任务一 · 提示词工程师（两轮迭代）

目标：写提示词让 AI 生成 new Swiper('#wySw4', {...}) 配置，满足 4 条硬性要求：① 无缝循环 ② 3.2 秒自动翻页且手动操作后不停止 ③ 圆点分页器可点击 ④ 初始效果 cube。

第一轮 · 朴素提示词（笼统版）

"帮我写一个 Swiper 配置，DOM 选择器是 #wySw4，需求：循环播放、自动播放每 3.2 秒、有圆点分页器、初始效果 cube。"

AI 第一轮回答（有 4 处硬伤）：

// 第一轮 · AI 朴素回答
new Swiper("#wySw4", {
  effect: "cube",
  loop: "true",                    // ❌ Bug1：字符串不是布尔值 → 不循环
  speed: 800,
  autoplay: { delay: 3200 },           // ❌ Bug2：漏 disableOnInteraction → 拖后停
  pagination: { el: "#wyPagination" },  // ❌ Bug3：id 写错 → 分页器消失
                                       // ❌ Bug4：漏 cubeEffect → cube 无阴影
});

第二轮 · 精准提示词（带约束版）

"修正上一轮的 4 个硬伤：① loop 必须是布尔值 true（不是字符串）；② autoplay 必须同时写 delay:3200 和 disableOnInteraction:false；③ pagination.el 写 '#wyPag4'（HTML 里的实际 id）并加 clickable:true；④ 补 cubeEffect 阴影参数。"

AI 第二轮回答（4 处全部修正）：

// 第二轮 · 精准修正版
function wySw4Config(fx) {
  return {
    effect: fx,
    loop: true,                                       // ✅ 布尔值
    speed: 800,
    autoplay: {
      delay: 3200,
      disableOnInteraction: false,                    // ✅ 拖后不停
    },
    pagination: {
      el: "#wyPag4",
      clickable: true,                              // ✅ 圆点可点
    },
    cubeEffect: { shadow: true, slideShadows: true, shadowOffset: 20, shadowScale: 0.94 }, // ✅ 立体阴影
  };
}
var wySw4Instance = new Swiper("#wySw4", wySw4Config("cube"));

验证结果

检查项第一轮第二轮
① 无缝循环FAIL loop="true" 字符串PASS loop=true 布尔
② 3.2s + 拖后不停FAIL 拖后 autoplay 停PASS disableOnInteraction=false
③ 圆点可点击FAIL id 写错消失PASS el=#wyPag4 + clickable
④ cube 立体FAIL 无阴影PASS cubeEffect 阴影生效
💡 心得：提示词的精度 = 结果的精度。第一轮只说"要什么"，AI 凭习惯瞎猜；第二轮把每条都拆成具体的布尔值/数字/字符串，AI 照着填就对了。

任务二 · creative 仿写（胶片影墙）

目标：课堂没讲过的 creative effect，读 Swiper 官方 CreativeEffectTransform 类型定义，仿写第 7 个效果。效果：上一张缩小左移带角度、下一张缩小右移带角度，像电影胶片条。

核心配置

creativeEffect: {
  prev: {
    translate: ['-15%', 0, -200],   // 左移 15%，Z 轴后退 200px（景深）
    rotate: [0, 0, 5],                // 顺时针转 5°（胶片倾斜）
    scale: 0.85,
    opacity: 0.55,
  },
  next: {
    translate: ['15%', 0, -200],    // 右移 15%，Z 轴后退
    rotate: [0, 0, -5],               // 逆时针转 5°（对称）
    scale: 0.85,
    opacity: 0.55,
  },
}

translate: [x, y, z] 三轴位移，rotate: [x, y, z] 三轴角度。胶片风格主要用 Z 轴旋转和 X/Z 位移。

答辩四连问速答

问题答案
keyboard 代码什么意思？enabled:true 开启键盘；onlyInViewport:false 表示不滚到可视区也能响应
AI 第一次错在哪？写成 keyboard:true（布尔值），Swiper 要求是对象 {enabled:true}；且没提 onlyInViewport
改了什么新参数？onlyInViewport 从默认 true 改为 false，避免页面没滚到时键盘无效
delay 改成指定值？改 autoplay.delay 字段即可，delay 是翻页间隔，speed 才是动画时长，两者独立
