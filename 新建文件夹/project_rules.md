# fjn 项目规则（Trae 项目规则）

## 项目说明
本项目为"文学社社"图书频道页面，1比1还原效果图（1.jpg / 2.jpg / 3.jpg 三种选项卡状态）。

## 编码规则（必须遵守）
1. 所有 CSS 类名必须以 `fjn_` 开头，例如 `.fjn_container`、`.fjn_book`。
2. 所有 id 必须以 `fjn_` 开头，例如 `#fjn_tabBar`。
3. 所有 JS 变量、函数名必须以 `fjn_` 开头，例如 `fjn_switchTab`、`fjn_tabs`。
4. 所有注释必须包含 fjn 标识，例如 `/* fjn 顶部标题区 */`。
5. 目录结构固定为：index.html + css/fjn_style.css + js/fjn_script.js + img/。

## 页面结构
- 顶部：标题"文学社社"，底部绿色（#77a80e）分隔线。
- 左栏（190px）：主编推荐 + 《虚实之间》推荐 + 底部三条推荐列表。
- 中栏（520px）：三个选项卡（流行小说 / 社科历史 / 文学艺术），每个选项卡对应 8 本书的图书列表（封面 100x140 + 书名 + 橙红价格）。
- 右栏（297px）：与选项卡联动的订阅榜（前 3 名红色数字，其余灰色，虚线分隔）。
- 交互：点击选项卡，JS 同时切换中栏图书面板与右栏订阅榜。
