任务一 · 提示词工程师不写代码写提示词：两轮迭代实录 + 真机验证

✍️ 任务要求

把需求"翻译"给 AI，生成 new Swiper('#wySw4', {...}) 配置：① 无缝循环 ② 3.2 秒自动翻页且手动操作后不停止 ③ 圆点分页器可点击 ④ 初始效果为 cube。至少迭代 2 轮提示词，保留每轮提示词与 AI 回答，粘进页面验证。

🧑 我（第 1 轮提示词 · 朴素版）
帮我用 Swiper 写一个轮播，选择器是 #wySw4：要无缝循环播放，3.2 秒自动翻页，带圆点分页器，圆点可以点击跳转，初始效果用 cube 立方体。
🤖 AI（第 1 轮回答 · 有 4 处错误）
好的，配置如下： 
var swiper = new Swiper('#wySw4', {    错误① 压根没写 loop
  autoplay: { delay: 3200 },           错误② 漏 disableOnInteraction:false
  pagination: { el: "#wyPagination", clickable: true },  错误③ id 猜错了
  effect: "Cube"                       错误④ 大小写错，Swiper 不识别
});
检查项现象结论
① 无缝循环整个 loop 参数没写，拖到最后一张就卡住不回卷FAIL
② 3.2 秒自动翻页·手动后不停没写 disableOnInteraction:false，配置缺失 —— Swiper 11 默认值恰好也是 false，行为侥幸没露馅，但需求没被显式实现FAIL
③ 圆点分页器可点击el 写成 #wyPagination，页面真实 id 是 #wyPag4，圆点不渲染FAIL
④ 初始效果 cubeeffect 写成 "Cube"（大写），Swiper 不识别，退回普通 slide，完全没有 3D 立方体FAIL

🧑 我（第 2 轮提示词 · 精准版：参数名 + 类型 + 值 + 原因）
重新给 #wySw4 写配置，逐条照做：
① loop: true —— 无缝循环要显式写上（上一轮整个漏了）；
② autoplay: { delay: 3200, disableOnInteraction: false } —— 需求"手动操作后不停止"必须显式落地，不能赌库的默认值；
③ pagination: { el: '#wyPag4', clickable: true } —— 页面里分页器容器真实 id 就是 #wyPag4，不要自己编；
④ effect: 'cube'（全小写，Swiper 才识别）+ cubeEffect: { shadow:true, slideShadows:true, shadowOffset:20, shadowScale:0.94 } 显式声明立体阴影；
⑤ speed: 800。除以上内容不要额外发挥。
🤖 AI（第 2 轮回答 · 4 处全部修正）
好的，逐条落实后的配置如下： 
var wySw4Instance = new Swiper('#wySw4', {
  loop: true,                          布尔值，循环生效
  speed: 800,
  autoplay: { delay: 3200, disableOnInteraction: false },  拖后不再停
  pagination: { el: '#wyPag4', clickable: true },          id 对上，可点
  effect: 'cube',
  cubeEffect: { shadow: true, slideShadows: true, shadowOffset: 20, shadowScale: 0.94 }  立体阴影
});

任务二 · creative 仿写课堂讲了 6 种，Swiper 其实有第 7 种 —— 自定义变换

✍️ 任务要求

打开官方示例 swiper/demo/257-effect-creative.html，配合 AI 读懂 creativeEffect 的 transform 写法，新增第 7 个按钮「creative 电影胶片」。效果：上一张缩小左移带角度、下一张放大右移进场，像电影选片墙。

我参考官方示例后让 AI 解释了 creativeEffect：prev 控制"上一张"离场姿态，next 控制"下一张"候场姿态。translate 三个值是 X/Y/Z 轴位移（百分比相对 slide 自身宽度），rotate 三个值是绕 X/Y/Z 轴的角度，第 3 个值（Z 轴）就是平面卡片上的旋转角。我的胶片参数：

creativeEffect: {
  prev: { translate: ['-15%', 0, -200], rotate: [0, 0, 5],  scale: 0.85, opacity: 0.55 },  上一张：左移15% + 沉入200px + 顺时针5°
  next: { translate: [ '15%', 0, -200], rotate: [0, 0, -5], scale: 0.85, opacity: 0.55 },  下一张：右移15% + 沉入200px + 逆时针5°
}

任务三 · 综合创作 + 技术答辩第六件展品「爱达·魔都号」+ keyboard 键盘控制 + zoom 双击放大 · 参考官方 demo 260

✍️ 任务要求

① 为光影展添加第六件展品「爱达·魔都号」（首艘国产大型邮轮，2024 年 1 月首航，图片用 AI 生成横版 16:9）；② 挑一个课堂没讲过的 Swiper 能力加上去：keyboard 键盘控制 / mousewheel 滚轮 / zoom 双击缩放 / parallax 视差，任选其一。

我选了 keyboard 键盘控制。做法：先打开 Swiper 官方包里的 demo/260-keyboard-control.html（官方键盘控制示例），读懂它的配置，再把里面能用的部分搬进光影展，改造成自己的轮播。

第一步 · 官方 demo 260 的原始配置（照抄自 demo 文件，它用 keyboard + 分页器 + 左右箭头）：

官方 demo/260-keyboard-control.html 原文：
var swiper = new Swiper(".mySwiper", {
  slidesPerView: 1,
  spaceBetween: 30,
  keyboard: { enabled: true },
  pagination: { el: ".swiper-pagination", clickable: true },
  navigation: { nextEl: ".swiper-button-next", prevEl: ".swiper-button-prev" }
});

第二步 · 我改造后的配置（换成自己的 id、加魔都号和自动播放，keyboard 补上 onlyInViewport）：

keyboard: { enabled: true, onlyInViewport: false },  demo 只写了 enabled；我补 onlyInViewport:false，轮播滚出屏幕也能响应按键
slidesPerView: 1,
spaceBetween: 30,  这两项来自官方 demo 260
loop: true,
autoplay: { delay: 3200, disableOnInteraction: false },
pagination: { el: '#fjnPagShip', clickable: true },
navigation: { nextEl: '#fjnNextShip', prevEl: '#fjnPrevShip' },  箭头也是 demo 260 带来的，id 换成自己的
zoom: { maxRatio: 3, minRatio: 1 }  双击图片放大 3 倍、再双击还原（slide 内要包 swiper-zoom-container）
